# ショート動画用アイキャッチ（上部テロップ画像）

作成日: 2026-07-25

ショート動画（縦1080×1920）の**上に重ねるアイキャッチ画像**の完成品と、文字を差し替えて量産するためのテンプレートです。`youtube-templates.md` §5のショート戦略（1銘柄1分／数字クイズ／人生スライス）に対応しています。

## 完成品（そのまま使える背景透過PNG）

| ファイル | 型 | 文言 |
|---|---|---|
| `アイキャッチA_貯金クイズ_透過.png` | 数字クイズ | 知らないと損／60歳の貯金額 平均いくら？ |
| `アイキャッチB_年金知らないと損_透過.png` | 年金×知らないと損 | 年金世代は必見／年金のコレ 知らないと損 |
| `アイキャッチC_パートで働く理由_透過.png` | 人生スライス | 資産1.6億円の元CA／それでも私がパートで働く理由 |
| `アイキャッチD_お金が入る株_透過.png` | 1銘柄1分 | 元CAの高配当株／持ってるだけでお金が入る株 |

## 使い方（編集アプリに重ねるだけ）

1. PNGをスマホに保存する
2. 動画編集アプリ（CapCut・VLLOなど）でショート動画の上に「画像を追加」で重ねる
   - 画像は1080×1920で作ってあるので、**画面全体にぴったり合わせるだけ**で正しい位置（上部）に表示されます。位置調整は不要です
3. 表示時間を動画の最初から最後まで（または冒頭3〜5秒だけ）に伸ばす

※ 上端150pxは空けてあるので、ショート再生画面の検索・カメラアイコンとは重なりません。

## 文字を変えて新しく作りたいとき

**いちばん簡単な方法**: チャットのAIに「ショートのアイキャッチ、文言は『○○○』で作って」と頼む（このフォルダのテンプレートで作り直してもらえます）。

自分で作る場合:

1. `generator.html` をメモ帳などで開き、`VARIANTS` の中の文字（badge=赤い帯、l1=1行目、l2=2行目）を書き換えて保存
2. ブラウザ（Chrome）で `generator.html` を開く
   - URLの末尾に `?v=A` 〜 `?v=D` を付けるとどの案を表示するか選べます
   - `?v=A&mode=preview` を付けると動画に重ねたイメージで確認できます
3. スクリーンショットを撮って使う（透過にしたい場合はAIに画像化まで依頼するのが確実です）

### 文言のルール（サムネと同じ）

- 1行13文字以内・2行まで。あふれた分は自動で縮小されますが、小さくなるほど弱くなります
- 赤字にするのは1〜2語だけ（「損」「いくら？」など、いちばん引っかかる言葉）
- 投資用語ではなく悩みの言葉を使う（変換辞書: `../youtube-タイトル書き換え案.md` §4）
