### 動画の渡し方

**このチャットに動画ファイルをそのまま添付（ドラッグ＆ドロップ）してください。**
届いた時点で、こちらで以下を一気にやります。

1. 全編を見て、ショート向きの「いちばん強い1区間」を選ぶ
2. その区間のセリフを1枚ずつ字幕に起こす
3. 上部アイキャッチの文言を、実際に話している内容に合わせて確定する
4. 1080×1920のmp4を書き出してリポジトリに追加する

ファイルが大きくて添付できない場合は、**スマホで撮った画面録画でも、YouTubeにアップ済みなら限定公開URLでも構いません**（URLの場合はこの環境から取りに行けないので、
その旨だけ先に教えてください。代わりの手順をご案内します）。

**ショートは3分が上限です。** 元動画が3分を超える場合は、必ずどこかを切り出すことになります。

## 1. 仕上がりの仕様（JAL版と同じ設計）

| 項目 | 内容 |
|---|---|
| 解像度・比率 | 1080×1920（9:16） |
| 尺 | 冒頭カード4.0秒 ＋ 本編（最大約2分50秒） |
| 上部の黒帯 | y=0〜600。**目立つアイキャッチ**（黄色の見出し＋白の大きなインパクト文）を話の切り替わりごとに差し替え |
| 映像パネル | y=600〜1080。元動画をここに配置 |
| 下部の黒帯 | y=1080〜1920。**白の特大文字（66〜96px）で全セリフを字幕化** |
| 上端の細い帯 | 「元JAL CA｜年間配当514万円までの実体験」を常時表示 |
| ラスト4.2秒 | 「▶ 本編はチャンネルから」 |

**元動画に字幕が焼き込まれている場合は、その帯を切り落としてから組み直します**（設定の `source_crop`）。
字幕が二重に出ることはありません。焼き込みが無い動画なら `source_crop` は `null` のままでOKです。

視聴者の94.5%が45歳以上・テレビ視聴20%というチャンネルの実測に合わせて、
**文字は大きく・行数は2行まで・改行位置は手で指定**しています（日本語を自動改行すると意味が変わるため）。

## 2. サムネイル3案（完成・そのまま使えます）

3案とも 1280×720（YouTubeの推奨サイズ）です。ショートの表紙用に 1080×1920 版も同時に作ってあります。

| 案 | ファイル | 文言 | 狙い |
|---|---|---|---|
| **A** 実績フック | `takahaitou-hajimekata_a_thumb_16x9.png` | 実話／元JAL CA・54歳<br>「何も知らなかった私が／配当だけで／**年514万円**」 | いちばん強い数字を正面に出す。実測で当たっている「実体験＋数字」型 |
| **B** タイトル直球 | `takahaitou-hajimekata_b_thumb_16x9.png` | 初心者向け／元JAL CA・年間配当514万円<br>「初めての／高配当株投資／**始め方のすべて**」 | 検索で来る人向け。YouTube検索が凪でも安定している唯一の流入なので、ここを取りにいく形 |
| **C** 疑問フック | `takahaitou-hajimekata_c_thumb_16x9.png` | 50代60代へ／元JAL CA・年間配当514万円<br>「高配当株、／何から買えばいい？／**最初の一歩**」 | 初心者が実際に検索する言葉をそのまま置いた形 |

**おすすめは A → C → B の順です。**
Aは数字が一つだけ大きく載っていて、テレビ画面でも小さいスマホ画面でも同じように読めます。
ただし「初めての〜」という動画の趣旨に忠実なのはCなので、**入門動画として伸ばしたいならCも強い**です。

### 顔写真について

**今回は文字だけのサムネイルにしています。** 手元にあるオーナーの写真素材は
JAL退職金の動画から切り出した1枚（泣いている表情）だけで、高配当株の入門動画には表情が合わないためです。

**笑顔・normal寄りの静止画を1枚いただければ、右側に顔を入れた版に作り直します**（そのほうがクリック率は上がります）。
設定ファイルの `portrait` にファイル名を入れるだけで自動で組み込まれる作りにしてあります。

### 文言を変えたいとき

`docs/assets/shorts/takahaitou-hajimekata.json` の `thumb_variants` を書き換えて、下記を実行するだけです。
文字の大きさは幅に合わせて自動調整されるので、長さを気にせず書き換えて構いません。

```bash
cd docs/assets/shorts
python3 make_short.py takahaitou-hajimekata.json --thumbs-only
```

## 4. 下部の字幕について

**全セリフを字幕にします。** これはJAL版と同じで、テレビ視聴20%・音を出さずに見る層が多いチャンネルでは
字幕の有無がそのまま視聴維持率に効くためです。

字幕の作り方は2通りあります。

1. **元動画に字幕が焼き込まれている場合** … こちらで1枚ずつ読み取って起こします。追加でやっていただくことはありません。
2. **焼き込みが無い場合** … この環境は音声認識モデルの配布元が遮断されているため、自動文字起こしができません。
   **台本や、動画の説明欄に入れた文字起こしがあれば、それを貼ってください。** 無ければこちらで映像から拾える範囲で組み、
   聞き取れない箇所をリストにしてお返しします。

字幕は `takahaitou-hajimekata.json` の `captions` に `[開始秒, 終了秒, "テキスト"]` の形で入ります。
テキストの中の `|` が改行位置です。

## 5. 作り方（元動画が届いたあと）

```bash
cd docs/assets/shorts
# 元動画を src.mp4 という名前でこのフォルダに置く
python3 make_short.py takahaitou-hajimekata.json
# → takahaitou-hajimekata/takahaitou-hajimekata_9x16.mp4
```

必要なもの: `ffmpeg`、Pythonの `pillow`、フォント `fonts-noto-cjk`。

設定ファイルでいじれるところ:

| キー | 内容 |
|---|---|
| `cut_in` / `cut_out` | 使う区間（元動画の秒） |
| `intro` | 冒頭カードの秒数 |
| `source_crop` | 元動画から切り出す範囲。焼き込み字幕を落とすときに使う |
| `layout.vid_y` / `layout.vid_h` | 映像パネルの位置と高さ |
| `eyecatch` | 上部アイキャッチ |
| `captions` | 下部の字幕 |
| `thumb_variants` | サムネイル各案 |
| `cover_variant` | どの案を冒頭カードに使うか |

`make_short.py` はこの動画専用ではありません。**別の動画をショートにするときは、設定ファイルをもう1つ作るだけです。**
