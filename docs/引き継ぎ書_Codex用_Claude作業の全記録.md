## 0. このプロジェクトの目的（オーナーの言葉）

> **YouTubeやブログで、人の役に立つ有益な情報を発信できるサイトにすること。**

数値目標は「月100万円の収益」「毎回100万回再生・登録者100万人」ですが、手段の優先順位は次のとおりです。

1. **人の役に立つことが先、収益は後からついてくる。** 50代60代が「知らないと損をする」年金・退職金・老後資金・終活の情報を、元JAL CAの実体験として正直に届ける
2. **正直さが信頼を生み、信頼が再生時間と収益を生む。** 煽り・誇張・断定はしない（投資助言業の登録がないため法的にもNG）
3. YouTube（本体）・ブログ（cabinattendant.blog）・無料ツール（このリポジトリのエンディングノート）が**互いに送客し合う**形を作る

## 4. 動画制作で確立した運用ルール（`SESSION_LOG.md` より・未マージ分の要点）

- **「答え合わせ」シリーズ**（過去ライブで話した企業の、その後の株価・配当の推移を検証する切り抜き）が視聴回数の武器。これまでに3本（2025/7/22爆買い回・2025/2/17銀行株回・2025/4/3「20%ルール」回）を納品

## 6. Codexが守ること（要点の再掲。正本は AGENTS.md §5〜7）

1. **個別企業の推奨・売買の断定・「必ず儲かる」はNG。** 体験の共有（「私はこうした」）はOK。投資の成果物には免責文を必ず付ける
   - 「本動画は個人の経験と考えの共有であり、特定の銘柄の売買を推奨するものではありません。投資はご自身の判断と責任でお願いします。」
2. 相続・税の話は一般論と体験談まで。個別の税額計算・申告の代行はしない（税理士法）
3. アフィリエイトは「PR」表記＋`rel="sponsored"`
4. 数字を推測で作らない。データはオーナーのスクリーンショット／貼り付けかWeb検索から。実績数値（資産額・配当額）は撮影時点の実数に更新する
5. 語り口は「諭さない・自分の話の形」。サムネ文字は大きく少なく（視聴者の2割がテレビ視聴）
6. オーナーは非エンジニア。成果物は**コピペで使える完成形**、手順は番号付きで画面のどこを押すかまで
7. `main` 直pushせず feature ブランチ＋PR。大きな動画ファイルはコミットしない
8. 新しい確定事実が出たら AGENTS.md §3 と analytics を更新し、このファイルの §3・§5 も更新して次のAIに引き継ぐ
