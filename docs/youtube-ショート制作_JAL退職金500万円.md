## 2. どの区間を使ったか（重要）

**元動画の 2:18.2〜3:10.9（138.2秒〜190.9秒）を使いました。** 全編ではありません。理由は2つです。

1. **YouTubeショートの上限は3分**。元動画は3分11秒あるので、そのままでは投稿できません。
2. **元動画には、写真が全画面になる区間（b-roll）が合計約68秒あり、そこは焼き込み字幕が隠れています。**
   この環境は音声認識モデルの配布元がネットワークポリシーで遮断されているため、その68秒のセリフだけは
   文字起こしできませんでした。「全部字幕」を成立させるには、字幕が全部取れている区間を使う必要がありました。

採用した52.7秒は**字幕が1枚も欠けておらず**、しかも「30年働いた退職金が合計500万円だった、その正体は」という
話が単体で完結する、いちばん強い区間です。

## 3. 冒頭のサムネイルカード（4.0秒）

YouTubeのサムネイル画像は、この環境からは取得が遮断されている（`i.ytimg.com` が403）ため、
**元動画の映像から作り直したサムネイル風カード**を貼っています。構成は以下。

- 赤バッジ「実話」＋「元JAL CA・30年勤務」
- 見出し「30年働いた／退職金は／**500万円**」（500万円は黄色）
- 右に本人カット
- 上に「この動画で話していること／30年働いた退職金が／なぜ500万円だったのか」
- 下に「受け取る日に言われたのは／「先に500万円 払って」／その理由とは」

**実物のサムネイル画像をお持ちなら、それに差し替えたほうが本編との一致感が出ます。**
画像を送っていただければ差し替えます。

```

```

ショートはタイトルより最初の1秒が効くので、タイトルは短いほうが有利です。

## 7. 作り直したいとき

```bash
cd docs/assets/shorts
python3 build_short.py        # 同じフォルダに元動画 src.mp4 と portrait.png が必要
```

必要なもの: `ffmpeg`、Pythonの `pillow`、フォント `fonts-noto-cjk`（Noto Sans CJK JP Black を使用）。

スクリプト冒頭の定数をいじれば調整できます。

- `CUT_IN` / `CUT_OUT` … 使う区間（元動画の秒）
- `INTRO` … サムネイルカードの秒数
- `VID_Y` / `VID_H` … 映像パネルの位置と高さ
- `CAPTIONS` … 字幕（`|` が改行位置）
- `EYECATCH` … 上部アイキャッチ

## 8. 運用メモ
