# 動画の概要欄に関連動画をつける指示書

## 目的

収益は視聴回数ではなく総再生時間に連動する。1本見た人にもう1本見てもらうのが、新規流入に頼らずに総再生時間を伸ばせる唯一の確実な手段。だから「おまけ」ではなく、動画公開作業の一部として毎回やる。

## 手順

### 1. 対象動画の「問い」を1文にする

タイトルではなく、その動画が視聴者に残した**未解決の気持ち**を書き出す。

- 例：「取り崩し中に暴落が来たら結果が変わる」→ 残る気持ちは「じゃあ私はどうすればいいの？」
- 例：「株はいつ売る？」→ 残る気持ちは「売らずに済む買い方はないの？」

この1文が、次に見せる動画を決める。

### 2. チャンネルの動画一覧を実際に見る

記憶で選ばない。https://www.youtube.com/@buffettkaoru/videos を開き、直近30〜40本のタイトル・再生数・公開時期を確認する。動画IDは `https://youtu.be/XXXXXXXXXXX` の短縮形で控える。

### 3. 優先順位に沿って3〜5本選ぶ

上から優先。同じ枠から2本選ばない（似た動画が並ぶと選べなくなる）。

1. **答え側の動画** — 対象動画が投げた問いに、別の角度から答えている動画。噛み合わせが最重要。
2. **私の実体験・口座公開系** — 「私はこう決めました」が入っている動画。信頼と滞在時間が両方伸びる。
3. **数字・キーワードが一致する動画** — 「2,000万円」「75歳」「暴落」など、対象動画に出てきた言葉が題名にある動画。視聴者が自分ごとにしやすい。
4. **落とし穴・続き** — 同じテーマの別リスク（税金、保険料、年金）に広げる動画。
5. **基礎編** — 初見の人の入り口になる「始め方」系。1本だけ入れておくと新規に効く。

加点する条件：

- 内容は良いのに再生数が伸びていない動画（救済になる）
- 直近1週間以内の動画（勢いに乗せられる）
- 8分以上の動画（総再生時間に効く。ショートや切り抜きは原則入れない）

除外する条件：

- 対象動画と内容が7割以上重なるもの（見る理由がなくなる）
- 相場や制度の数字が古くなっているもの
- 限定公開・非公開のもの

### 4. 1行説明を書く

タイトルをそのまま貼らない。タイトルは煽り、概要欄の1行は**中身の約束**にする。語り口は AGENTS.md「語り口」の通り、諭さず自分の話の形で書く。

- ✕ 「株はいつ売る？私が一度も損切りしていない理由」（タイトルのコピペ）
- ○ 「暴落で売らない、の具体的な線引きを5つにまとめました」
- ✕ 「皆さんも確認しましょう」（教える言い方）
- ○ 「私がS&P500を全部売って、高配当の企業に移した理由」

「株」「銘柄」ではなく「企業」「会社」を主語にする。

### 5. 概要欄に貼る

位置は「【この動画の内容】」の直後、チャンネル登録のお願いより前。概要欄を開いた人の目に最初に入る場所。

```
▼この動画の続き・関連
・（1行説明）
　https://youtu.be/XXXXXXXXXXX
・（1行説明）
　https://youtu.be/XXXXXXXXXXX
・（1行説明）
　https://youtu.be/XXXXXXXXXXX
```

- 4本まで。5本を超えるとクリックが分散して、どれも押されなくなる。
- URLは必ず改行して全角スペース1つで字下げ。スマホで折り返しても読める。
- 証券口座などのアフィリエイトリンク（PR表記あり）とは離して置く。混ざるとどちらも信用されない。

### 6. 終了画面（2枠）

- 左：**優先順位1位の動画**を固定で置く
- 右：チャンネル登録ボタン、または優先順位2位の動画
- 「視聴者に最適な動画」は使わない。他チャンネルに流れる。
- 表示は最後の20秒。本編の話が終わりきる前から出す（無音の締めに入ると離脱する）。

### 7. カード

- その話題に**触れた直後**に1枚。話の途中で被せない。
- 1本の動画に2枚まで。
- 視聴者の94%が45歳以上、2割はテレビ画面で見ている。テレビではカードは押せないので、カードで出した動画は必ず概要欄と終了画面にも入れておく。

## 完成前チェック

- [ ] リンクは全部踏んで、正しい動画が開くか確認した
- [ ] 3〜4本に収まっているか
- [ ] 「〜すべき」「〜しましょう」「皆さんも」が入っていないか
- [ ] 断定表現・個別銘柄の推奨になっていないか（投資助言業の登録なし）
- [ ] 免責表記が概要欄に残っているか
- [ ] アフィリエイトリンクにPR表記があるか

## 出力のしかた

提案するときは、選んだ動画ごとに「なぜこの動画か」を1〜2文で添える。そのうえで、そのまま概要欄に貼れる完成形のブロックをコードブロックで出す。かおるさんが編集画面に貼るだけで済む状態にする。
